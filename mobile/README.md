# SevakAI Mobile (Flutter)

ASHA worker Android app: login, patient list with risk badges, voice-record
a home visit, offline queue + auto-sync, follow-up task list (SRS FR-07).

## This is a code skeleton, not yet a buildable Flutter project

`lib/` has real, complete Dart source for every screen and service. What's
missing are the native platform folders (`android/`, `ios/`, etc.) that
`flutter create` normally generates -- they weren't hand-written here
because they're boilerplate best generated by the actual Flutter tooling
for whatever Flutter version you install.

**First-time setup:**

```bash
cd mobile
flutter create . --project-name sevakai_mobile --org com.sevakai   # fills in android/, ios/, etc. -- keeps lib/ and pubspec.yaml
flutter pub get
flutter run   # with an emulator or device attached
```

If `flutter create .` complains the directory isn't empty, that's expected
-- it only adds the platform folders it doesn't find, and leaves `lib/`
and `pubspec.yaml` alone.

## Pointing at the backend

`lib/services/api_client.dart` defaults to `http://10.0.2.2:8000`, which is
how the Android emulator reaches `localhost` on your dev machine (where
`../backend` should be running -- see its README). On a physical device,
change `baseUrl` to your machine's LAN IP.

## Layout

```
lib/
  main.dart                  App entry point, launches LoginScreen
  models/                    Patient, FollowupTask -- mirror backend Pydantic schemas
  services/
    api_client.dart          HTTP calls to the FastAPI backend
    offline_queue.dart       sqflite-backed sync_queue (offline recording)
    sync_service.dart        Watches connectivity, flushes the queue automatically
  screens/
    login_screen.dart        Phone + PIN -> JWT (demo: 9999999999 / 1234)
    patient_list_screen.dart FR-07.2: patient list + risk badges
    voice_record_screen.dart FR-01.1/01.3: record, submit or queue offline
    task_list_screen.dart    FR-07.3: pending follow-ups sorted by urgency
  widgets/risk_badge.dart    RED/YELLOW/GREEN dot
```
